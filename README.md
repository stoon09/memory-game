# Memory Game

Игра на поиск пар: нужно открывать карточки по две и находить все 8 пар за наименьшее число ходов.

**Демо:** https://stoon09.github.io/memory-game/

## Возможности

- поле из 16 карточек (8 пар), перемешивание при каждой новой игре
- счётчики ходов и найденных пар
- модальное окно победы
- таблица лидеров (10 лучших результатов), хранится в localStorage
- кнопка «Новая игра» работает в любой момент

## Технологии

HTML, CSS, JavaScript. Без библиотек и фреймворков, весь интерфейс создаётся через `document.createElement`.

## Запуск локально

1. Склонируйте репозиторий: `git clone https://github.com/stoon09/memory-game.git`
2. Перейдите в ветку: `git switch memory-game`
3. Откройте файл `index.html` в браузере (или запустите расширение Live Server в VS Code).

Установка зависимостей и сборка не требуются.
